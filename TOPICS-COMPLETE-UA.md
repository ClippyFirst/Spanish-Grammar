# Повний список тем іспанської граматики
## для довідника українською (Spanish-Grammar)

> **Призначення:** єдиний контрольний список усього, що має бути в проєкті, щоб україномовний користувач міг користуватися ним як повноцінним довідником — від абетки до тонких синтаксичних і регіональних явищ.
>
> **Не** навчальний план за рівнями CEFR і **не** курс.
> Це **карта покриття** граматичної системи + пріоритети саме для носіїв української.
>
> Оновлювати при додаванні/закритті тем. Статус: ✅ є · 🟡 частково · ❌ немає · ⭐ критично для UA.

---

## Принципи відбору

1. **Уся практично значуща граматика** іспанської (морфологія, синтаксис, словозміна, службові слова, складні речення, регіональні варіанти, регістр).
2. **Акцент на інтерференції UA→ES:** артиклі, ser/estar/hay, indefinido/imperfecto, subjuntivo, por/para, особове a, gustar, подвійне заперечення, порядок клітиків, умовні після si.
3. Кожна тема в контенті: логіка → утворення → вживання / невживання → приклади з перекладом → помилки UA → регіон (де треба) → related.
4. Без лексичних словників «просто слів»; приклади лише для граматики.
5. Одна глибока сторінка може закривати кілька підтем; мікроявища — у Note або в головній темі.

# 17. Мікроконструкції та «тонкі» явища

> Покривати в релевантних сторінках (Note) або окремо, якщо тема розростається.

- [ ] Емфатичне / контрастивне **sí** (él sí lo sabe)
- [ ] Дублювання клітиком (A Juan le dije…; contigo no quiero hablar a ti — норми)
- [ ] Se «етичне» / аспектуальне / інхоативне (se me olvidó; se comió toda la tarta; se cayó)
- [ ] Pero vs sino / sino que
- [ ] Por qué / porque / porqué / por que
- [ ] A vs en з рухом і місцем
- [ ] De + інфінітив після іменників і прикметників (la idea de viajar; contento de ver)
- [ ] Умовний без si (de haberlo sabido…; como si…)
- [ ] Ojalá / así / quien + subjuntivo (бажальні)
- [ ] Номінативні абсолютні / абсолютний participio (terminada la reunión…)
- [ ] Cuanto más… más…; lo antes posible…
- [ ] Será que… / ¿será que…? (припущення)
- [ ] No sea que… / por si…
- [ ] Lo de + INF / lo de que…

# 18. Пріоритет ⭐ для україномовних (обов’язково глибоко)

Ці теми **не можна** лишати тонкими — саме тут найбільше помилок і запитів:

1. Артиклі (el/un/нуль) і lo
2. Ser / estar / hay
3. Indefinido vs imperfecto (+ perfecto в Іспанії vs Америці)
4. Por vs para
5. Subjuntivo: тригери і «коли ні»; ojalá; como si
6. Займенники-додатки + позиція + se lo + дублювання OI
7. Особове a
8. Gustar-тип
9. Заперечення (nadie/nada + no; tampoco)
10. Умовні (si + часи; **без** condicional після si)
11. Voseo / ustedes vs vosotros
12. Карта інтерференцій UA
13. Haber допоміжне vs hay vs tener
14. Відносні (que / quien / cuyo) + subjuntivo при невідомому антецеденті

# 19. Що свідомо **не** є окремими «граматичними» сторінками

- Лексичні списки слів без граматичного сенсу
- Культурологічні есе без граматики
- Вправи / тести (окремий продукт, якщо знадобиться)
- Повний фонетичний курс (лише те, що впливає на письмо й граматику: ñ, ü, yeísmo, seseo)
- Історія мови (крім коротких пояснень форм на кшталт futuro de subjuntivo)
