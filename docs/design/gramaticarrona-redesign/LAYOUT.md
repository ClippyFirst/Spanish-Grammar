# Layout — Gramaticarrona Redesign

## Загальна структура (Desktop ≈ 1440px)

```
┌──────────┬────────────────────────────────────────────────────────────┐
│          │  Header (logo + nav)                                       │
│  Index   ├────────────────────────────────────────────────────────────┤
│  Stripe  │                                                            │
│  01–17   │  Main content                                              │
│  (88px)  │  padding-left/right: 56px                                  │
│          │                                                            │
│          │  Footer                                                    │
└──────────┴────────────────────────────────────────────────────────────┘
```

- Фон сторінки: `--color-paper` (`#F3F0E7`)
- Індекс-смуга: `--color-stripe` (`#E3DDCB`), фіксована ширина 88px
- Контентна колонка: решта ширини, білий фон у більшості блоків

## Індекс-смуга (Index Stripe)

- 17 осередків (по одній на категорію)
- Кожен осередок: висота ~40px, текст 01…17 (IBM Plex Mono, 12px)
- **Неактивна**: фон `#E3DDCB`, текст `#55524A`
- **Активна**: фон `#C13A1E`, текст `#FBFAF6`, weight 600
- Смуга завжди видима (навіть коли відкрита конкретна тема) — працює як покажчик паперового довідника

## Header

- Висота ≈ 66–70px
- Ліворуч: логотип «Gramaticarrona» (Fraunces 900, 21px)
- Праворуч: Категорії · Порівняння · Про проєкт · **Пошук ⌕** (посилання `#1F3A5F`, weight 600)
- Під хедером — тонка лінія `#C9C2B2`

## Контентна зона

- Горизонтальні відступи: 56px
- Вертикальні секції з чіткими роздільниками
- Overline (ДОВІДНИК, КАТЕГОРІЇ — 17, ПОПУЛЯРНЕ тощо) — uppercase / letter-spacing, muted color

## Breakpoints (орієнтовно)

| Назва | Ширина | Поведінка |
|-------|--------|-----------|
| Desktop | ≥ 1200px | Повна смуга + 56px padding |
| Tablet | 768–1199px | Смуга може звужуватися або ховатися в меню |
| Mobile | ≤ 767px (дизайн 390px) | Смуга зникає → бургер-меню; padding 20px |
