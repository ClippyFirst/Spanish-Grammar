# Pages — Gramaticarrona Redesign

## 1. Home

**Мета**: швидкий вхід у довідник.

Блоки (зверху вниз):
1. Header
2. Overline «ДОВІДНИК»
3. H1 «Іспанська граматика для українськомовних»
4. Підзаголовок + лічильник тем (231)
5. Чотири кроки: `01 ЗНАЙТИ | 02 ЗРОЗУМІТИ | 03 ПОРІВНЯТИ | 04 ЗАПАМ’ЯТАТИ`
6. Список категорій (вибірка 8–9 з 17 + примітка «і ще 9…»)
7. Блок «Популярне» (5 тем з level badges)
8. Footer

Індекс-смуга: жодна категорія не активна (або 01 за замовчуванням — за рішенням).

## 2. Category (напр. 09 Дієслова)

1. Header
2. Breadcrumbs: `Категорії / Дієслова`
3. Великий номер `09` (accent) + назва категорії + іспанська назва + опис
4. Список тем `ТЕМИ — 21` з кодами 09.01…, популярними маркерами, level badges
5. Footer

Індекс-смуга: активна відповідна категорія (09).

## 3. Topic / Article (напр. 09.01 Ser та Estar)

1. Header
2. Breadcrumbs
3. Код теми + level badge + «● популярне» (якщо є)
4. H1 (UK) + підзаголовок (ES) + короткий вступ
5. Товста чорна лінія-роздільник
6. Секції контенту:
   - Швидка формула (Formula boxes + Token chips)
   - Нотатка «Для носіїв української»
   - Коли SER / Коли ESTAR (два стовпчики)
   - Мінімальні пари
   - Типові помилки (Mistake corrections)
   - Регіональна нота
   - Пов’язані теми
7. Footer

Індекс-смуга: активна категорія теми.

## 4. Search

1. Header
2. Overline «ПОШУК»
3. H1 «Знайти тему»
4. Search input (великий, outline)
5. Підказка під полем
6. Результати: «РЕЗУЛЬТАТИ — N» + запит
7. Список result items (код, title, description, level)

## 5. 404

1. Header
2. Великий 404 + текст «Схоже, це правило загубилося у відмінюванні.»
3. Короткий опис
4. Кнопки: «← На головну» (primary) + «Відкрити пошук» (outline)
5. Блок «Продовжити з категорії» (список 01, 09, 10, 11…)
6. Footer
