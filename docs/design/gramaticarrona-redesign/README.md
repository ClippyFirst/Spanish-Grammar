# Gramaticarrona — редизайн (Design Requirements)

Джерело: Figma «Gramaticarrona — редизайн»  
Дата фіксації: 2026-09-24  
Статус: **вимоги** (не реалізація). Технічну імплементацію робить власник репозиторію.

## Концепція

Інтерфейс — **редакційний лінгвістичний атлас** (editorial linguistic atlas).
Типографіка на першому місці, інформаційна щільність, стримана палітра, чітка ієрархія.
Не SaaS-стиль, не «карточный» UI.

Принцип продукту (зберігається):
**знайти → зрозуміти → порівняти → запам’ятати**

## Ключові відмінності від поточного дизайну

1. **Індекс-смуга зліва** (88px) — постійний показчик 17 категорій, активна підсвічується акцентом.
2. **Нова палітра** — паперовий фон `#F3F0E7`, акцент `#C13A1E`, посилання `#1F3A5F`.
3. **Типографіка**: Fraunces (заголовки) + Inter (текст) + IBM Plex Mono (формули/коди).
4. **Token-компоненти** з кольоровими чіпами (ПІДМЕТ / ДІЄСЛОВО / …).
5. **Рівні CEFR** (A1–B2) як бейджі.
6. **Мінімальні пари** і блок «типові помилки» з червоним → зеленим виправленням.

## Що не входить у цей пакет

- Готовий CSS / Astro-компоненти (технічна сторона — окремо).
- Зміни content model / MDX-схеми.
- Анімації чи інтерактивні прототипи.
