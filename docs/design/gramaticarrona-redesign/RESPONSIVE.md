# Responsive — Gramaticarrona Redesign

## Mobile (дизайн ~390px)

З Figma є окремий фрейм «Мобільна стаття — Ser та Estar».

### Зміни відносно Desktop

| Елемент | Desktop | Mobile |
|---------|---------|--------|
| Index stripe | 88px завжди видима | Ховається; доступ через меню |
| Header | Logo + повна nav | Logo + «МЕНЮ ☰» |
| Content padding | 56px | 20px |
| H1 topic | ~40–46px | ~36px, line-height 40px |
| Formula boxes | Два поруч | Один під одним, chips можуть wrap |
| Minimal pairs | Два стовпчики | Один під одним |
| Mistake block | Горизонтально | Вертикально (неправильно → правильно) |
| Footer | 11px | 9px |

### Поведінка меню

- Бургер відкриває повну навігацію + список категорій (або індекс-смугу у вигляді списку).
- Активна категорія має бути помітна і в меню.

### Читабельність

- Зберігати комфортну міру рядка (не розтягувати текст на всю ширину без обмеження).
- Token chips і бейджі залишаються читабельними (не зменшувати нижче 10px).
- Touch targets ≥ 44px для клікабельних елементів.

## Tablet

- Можна залишити спрощену смугу або перейти на mobile-патерн раніше (≤ 900–1000px).
- Formula boxes можуть залишатися в два стовпчики довше, ніж інший контент.

## Принцип

Редакційний характер зберігається на всіх розмірах: спочатку типографіка і ієрархія, потім декоративні елементи.
