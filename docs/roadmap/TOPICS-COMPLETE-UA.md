# Повний список тем іспанської граматики
## для довідника українською (Spanish-Grammar)

> **Призначення:** єдиний контрольний список усього, що має бути в проєкті, щоб україномовний користувач міг користуватися ним як повноцінним довідником — від абетки до тонких синтаксичних, регіональних і прагматичних явищ.
>
> **Не** навчальний план за CEFR і **не** курс.
> Це **карта покриття** граматичної системи + пріоритети для носіїв української.
>
> Статус: ✅ є · 🟡 частково · ❌ немає · ⭐ критично для UA.
>
> **Орієнтир:** *Plan curricular del Instituto Cervantes* (PCIC) — інвентар Gramática + Ortografía; плюс мікроконструкції фокусу/полярності.
>
> **Ця версія = суперінсет усіх попередніх комітів файлу** (4554d55 → 40ec45f → 24af168 → c0bbeba → 3bf99ab).

## Принципи відбору

1. **Уся практично значуща граматика** іспанської (морфологія, синтаксис, словозміна, службові слова, складні речення, регіональні варіанти, регістр, фокус/полярність).
2. **Акцент на інтерференції UA→ES:** артиклі, ser/estar/hay, indefinido/imperfecto, subjuntivo, por/para, особове a, gustar, подвійне заперечення, порядок клітиків, умовні після si, частини тіла + артикль, кальки з EN *do*.
3. Кожна тема в контенті: логіка → утворення → вживання / невживання → приклади з перекладом → помилки UA → регіон (де треба) → related.
4. Без лексичних словників «просто слів»; приклади лише для граматики.
5. Одна глибока сторінка може закривати кілька підтем; мікроявища — у Note або в головній темі.

# 17. Мікроконструкції, фокус і полярність ⭐

> «Екзотика», без якої важко звучати впевнено. Багато з цього — відповідь на EN *do*-support і на UA кальки.

## 17.1. Емфаза полярності: **sí** (≈ англ. *do* / *does* / *did*)

- [ ] **Yo sí quiero tener…** / **Él sí lo sabe** — ствердження всупереч очікуванню чи запереченню ⭐
- [ ] Контраст: *No quiero café. — Yo **sí** quiero.*
- [ ] *Sí* після підмета vs на початку: *Yo sí voy* / *Sí voy*
- [ ] Відмінність від стверджувального *sí* (= «так») і від *si* (якщо) — орфографія з тільдою
- [ ] **Sí que…** — підсилення (*Sí que es caro*)
- [ ] *Pues sí*, *claro que sí*, *sí, sí* — дискурсивні відповіді
- [ ] Негативний «двійник»: *Yo no…* з контрастом (*Yo no lo haría*)

## 17.2. Заперечення і «не те, а…»

- [ ] **No… sino / sino que** (не X, а Y) ⭐
- [ ] **No es que… (sino que)…** — відхилення пояснення (*No es que no quiera, es que no puedo*)
- [ ] **No es porque…** + subjuntivo / indicativo
- [ ] *Tampoco* vs *también*; *ni… ni*
- [ ] Подвійне заперечення як норма + емфатичне *nada de…*

## 17.3. Фокус, топік, дислокація

- [ ] Ліва / права **дислокація** з клітиком (*El libro, lo leí ayer*)
- [ ] Топік vs фокус: інтонація + порядок
- [ ] Cleft / pseudocleft: *Lo que quiero es…*; *Es a Juan a quien…*
- [ ] **Verum focus** (часто через *sí* / *sí que*)
- [ ] Емфатичний підмет (*YO lo hice*)

## 17.4. Se і «дрібні» актанти

- [ ] Se етичне / зацікавленості (*se me olvidó*; *no se me ocurre*)
- [ ] Se аспектуальне / інхоативне (*se comió toda la tarta*; *se cayó*)
- [ ] Dativo posesivo + **частини тіла** (*me lavo las manos*; *me duele la cabeza*) ⭐

## 17.5. Незалежний / «вільний» subjuntivo

- [ ] Бажальні / наказові без головного: *¡Que te vaya bien!*; *¡Viva…!*; *Ojalá…*
- [ ] *Que* + subjuntivo як м’який наказ / побажання третій особі
- [ ] *Como si* + imperfecto / pluscuamperfecto de subjuntivo

## 17.6. Час і аспект «по-дорослому»

- [ ] *Hace dos años (que)…*; *desde hace…*; *desde 2019*
- [ ] *Ya* / *todavía* / *aún* / *ya no*
- [ ] *Llevar* + gerundio / *hace… que* + presente (тривалість дотепер)

## 17.7. Інші «дорослі» конструкції

- [ ] *De* + INF умовно (*De haberlo sabido…*)
- [ ] *Será que…* / *¿Será que…?* — припущення
- [ ] *No sea que…* / *por si…* / *por si acaso*
- [ ] *Lo de* + N / INF / *que*…
- [ ] *Cuanto más… más…*; *lo antes posible*
- [ ] *Al* + INF (*Al llegar…*) — часова одночасність
- [ ] Абсолютний participio / gerundio (*Terminada la reunión…*; *Estando yo allí…*) — розпізнавання
- [ ] Por qué / porque / porqué / por que
- [ ] A vs en з рухом і місцем
- [ ] De + інфінітив після іменників і прикметників (*la idea de viajar*; *contento de ver*)
- [ ] *Como que* (розмовне «типу / начебто») — регістр
- [ ] *En plan* (Ісп., молодіжний) — регістр
- [ ] Reduplicación емфатична (*rápido rápido*)

## 17.8. Чого **не** калькувати з англійської / української

- [ ] Англ. *do*-support → **не** *hacer* (**Yo hago quiero*), а **sí** / інтонація / порядок ⭐
- [ ] UA «та я ж хочу» → часто *Yo sí quiero* / *Sí que quiero*
- [ ] UA «моя голова болить» → *me duele **la** cabeza* (не *mi cabeza*)
- [ ] UA «я став учителем» → вибір *hacerse / convertirse / llegar a ser / ponerse*
- [ ] *I am the one who…* → cleft *Soy yo quien…* / *El que… soy yo*

# 18. Пріоритет ⭐ для україномовних (обов’язково глибоко)

1. Артиклі (el/un/нуль) + nombres escuetos + lo
2. Ser / estar / hay
3. Indefinido vs imperfecto (+ perfecto в Іспанії vs Америці)
4. Por vs para
5. Subjuntivo: тригери і «коли ні»; ojalá; como si
6. Займенники-додатки + позиція + se lo + дублювання OI + dativo posesivo
7. Особове a
8. Gustar-тип
9. Заперечення (nadie/nada + no; tampoco)
10. Умовні (si + часи; **без** condicional після si)
11. Voseo / ustedes vs vosotros
12. Карта інтерференцій UA
13. Haber допоміжне vs hay vs tener
14. Відносні (que / quien / cuyo) + subjuntivo при невідомому антецеденті
15. **Емфатичне sí / sí que** (полярність; анти-калька *do*) ⭐
16. **No… sino / no es que…**
17. **Частини тіла + артикль + dativo** (*me duele la cabeza*) ⭐
18. **Hace / desde hace / ya–todavía**
19. **Зміна стану** (ponerse, volverse, hacerse…)

# 19. Що свідомо **не** є окремими «граматичними» сторінками

- Лексичні списки слів без граматичного сенсу
- Культурологічні есе без граматики
- Вправи / тести (окремий продукт, якщо знадобиться)
- Повний фонетичний курс (лише те, що впливає на письмо й граматику: ñ, ü, yeísmo, seseo)
- Історія мови (крім коротких пояснень форм на кшталт futuro de subjuntivo)
- Чисті «функції» PCIC без граматичного ядра (можна cross-link пізніше)
