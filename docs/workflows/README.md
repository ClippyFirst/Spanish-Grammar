# Workflow documents

This directory contains working material used to execute and document the editorial workflow.

- `EXECUTION-LOG.md` — chronological project execution record.
- `content-plan.md` — content planning material.
- `plan-standardization-prompts.md` — standardization planning.
- `prompt_content.txt`, `prompt_themes.txt`, `prompt_website.txt` — reusable workflow prompts.

Keep active workflow material here rather than adding working notes to the repository root.
