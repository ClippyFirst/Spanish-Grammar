# MASTER PROMPT — Spanish Grammar Reference for Ukrainian Speakers

You are the lead software architect, UX/UI designer, frontend engineer and technical product designer.

Your task is to build a modern, fast, static-first grammar reference website dedicated initially to SPANISH GRAMMAR FOR UKRAINIAN-SPEAKING LEARNERS.

The website is NOT a language course.

It is NOT a vocabulary trainer.

It is NOT a flashcard application.

It is NOT primarily organized by CEFR levels.

It is a comprehensive grammar REFERENCE: a place where a Ukrainian-speaking learner can quickly find a grammatical topic, understand it deeply, see clear formulas and examples, understand exceptions and common mistakes, and navigate to related topics.

The core UX principle is:

"Find → understand → compare → remember."

The website should preserve the strongest ideas of GrammarWay while substantially improving its information architecture, search, explanations, examples, error correction, regional notes and navigation.

==================================================
1. TARGET AUDIENCE
==================================================

Primary audience:

Ukrainian-speaking people learning Spanish.

They may be beginners, intermediate learners or advanced learners, but DO NOT expose CEFR levels as the primary organizational principle.

The site must be understandable specifically to Ukrainian speakers.

Therefore explanations must:

- be written in natural Ukrainian;
- explicitly explain differences between Ukrainian and Spanish where useful;
- anticipate errors caused by Ukrainian language structure;
- avoid explanations that assume English as the learner's native language;
- use English terminology only when useful for international terminology/SEO;
- never make English the hidden pedagogical reference language.

The user should be able to understand:

"Why does Spanish work this way?"

rather than merely memorize:

"Spanish uses this form."

==================================================
2. PRODUCT CONCEPT
==================================================

Build a grammar reference with:

- extremely clear structure;
- concise explanation first;
- deeper explanation below;
- visual formulas;
- conjugation tables;
- examples in Spanish + Ukrainian translation;
- minimal pairs;
- common mistakes;
- exceptions;
- regional variation;
- related topics;
- comparisons where useful;
- powerful client-side search;
- breadcrumbs;
- table of contents for long pages;
- mobile-first responsive design.

The site should feel like:

- a modern reference book;
- a high-quality digital grammar handbook;
- a clean technical documentation site.

It should NOT feel like:

- Duolingo;
- a gamified language-learning application;
- a blog;
- a course platform;
- a social network.

==================================================

==================================================

Prioritize:

CLARITY > DECORATION

READABILITY > INFORMATION DENSITY

REFERENCE VALUE > GAMIFICATION

CONTENT QUALITY > ANIMATION

The interface must be calm, clean and professional.

- gradients;
- excessive animations;
- decorative illustrations;
- huge hero sections;
- cards everywhere;
- excessive colors;
- gamification.

10. GRAMMAR PAGE DESIGN
==================================================

Every grammar page should follow a consistent structure.

Recommended structure:

1. Breadcrumbs
2. Title
3. One-sentence explanation
4. Quick Formula / Quick Reference
5. Formation
6. Usage
7. Examples
8. Time markers / trigger expressions where relevant
9. Exceptions & special cases
10. Common mistakes
11. Ukrainian-specific notes
12. Regional notes
13. Comparison
14. Related topics
15. Optional practice

The first screen should answer:

"What is this?"

and:

"How is it formed?"

without requiring the user to read the entire article.

==================================================
11. QUICK FORMULA COMPONENT
==================================================

Create reusable components for:

- affirmative;
- negative;
- interrogative.

For example:

AFFIRMATIVE
Subject + conjugated verb + ...

NEGATIVE
Subject + no + conjugated verb + ...

QUESTION
¿...?

However, do NOT force the three-column structure when it is grammatically inappropriate.

For conjugation topics use conjugation tables.

For noun topics use agreement tables.

For pronouns use position/form tables.

The component must adapt to the grammar topic.

==================================================
12. FORMULA VISUAL LANGUAGE
==================================================

Create reusable visual tokens for:

- subject;
- auxiliary verb;
- conjugated verb;
- infinitive;
- participle;
- pronoun;
- negation;
- ending;
- preposition;
- variable element.

The visual language should help the learner understand structure.

Do not rely solely on color.

Every visual distinction must remain understandable without color.

==================================================
13. EXAMPLE COMPONENT
==================================================

Each example should support:

Spanish sentence
Ukrainian translation
Optional grammatical annotation
Optional explanation

Example:

Me gusta el café.

Мені подобається кава.

Important:
The Ukrainian translation must sound natural.

Do not produce mechanically translated Ukrainian.

==================================================
14. MINIMAL PAIRS
==================================================

Use minimal pairs whenever they clarify a difficult distinction.

For example:

Soy médico.
Я лікар.

Estoy cansado.
Я втомлений.

Then explain why the Spanish verbs differ.

Minimal pairs are especially important for:

- ser / estar;
- por / para;
- pretérito / imperfecto;
- indicative / subjunctive;
- object pronouns;
- articles;
- demonstratives;
- prepositions.

==================================================
15. COMMON MISTAKES
==================================================

Every important grammar page should contain:

"Типові помилки україномовних"

Each mistake should include:

❌ incorrect
✅ correct
Why?

The explanation must explain the underlying reason.

Do not simply say:

"Так неправильно."

==================================================
16. UKRAINIAN-SPECIFIC PEDAGOGY
==================================================

This is one of the most important requirements.

Whenever Spanish grammar differs significantly from Ukrainian, explicitly explain the difference.

Examples:

- Spanish grammatical gender vs Ukrainian grammatical gender.
- Spanish articles where Ukrainian has no articles.
- Spanish subject omission.
- Spanish object pronouns.
- Spanish personal a.
- Spanish ser/estar.
- Spanish subjunctive.
- Spanish double negation.
- Spanish gustar construction.
- Spanish word order.
- Spanish prepositions.

Do not assume English grammar as the default comparison.

English may be mentioned when genuinely useful, but Ukrainian is the primary pedagogical reference.

==================================================
17. REGIONAL VARIATION
==================================================

Spanish is pluricentric.

Do not present one regional variety as the only "correct Spanish".

Where relevant, distinguish:

- Spain;
- Latin America;
- Rioplatense Spanish;
- Mexico/Central America;
- Caribbean where relevant.

Important topics:

- tú / vos / usted;
- vosotros / ustedes;
- voseo;
- seseo / distinction / ceceo;
- leísmo / laísmo / loísmo;
- regional vocabulary only when it affects grammar;
- regional imperative forms.

Regional information should be concise on ordinary pages.

Create deeper dedicated regional pages where necessary.

==================================================
18. CONTENT DEPTH
==================================================

The site must be deep.

"Deep" does NOT mean unnecessarily verbose.

Each topic should answer:

- What is it?
- How is it formed?
- When is it used?
- When is it NOT used?
- What are the exceptions?
- What are the common mistakes?
- What does a Ukrainian speaker usually misunderstand?
- What are the important regional differences?
- What related grammar should the learner know?

For major topics, provide enough examples to demonstrate the rule rather than merely state it.
