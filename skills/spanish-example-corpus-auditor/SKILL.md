# Spanish Example Corpus Auditor

## Goals
Every example should have a clear job: illustrate a rule, contrast two forms, show a boundary case, or demonstrate a common context. Examples must not merely contain a target word.

## Procedure
1. Assign each example an ID and target construction.
2. Record meaning/context, intended variety and register, translation if present, source/provenance and confidence.
3. Check grammaticality and idiomaticity separately; route uncertainty to fact-checking and variation review.
4. Test whether the example isolates the target feature or relies on unexplained grammar.
5. For contrast pages, use minimally different pairs where changing the target form changes meaning or acceptability for a reason.
6. Include positive cases, counterexamples and boundary cases; avoid repetitive examples with the same lexical frame.
7. Check translation alignment without demanding word-for-word equivalence.
8. Identify duplicate templates, implausible scenarios, ambiguous context and examples that accidentally teach an unintended rule.
9. Recommend regression tests for every corrected high-risk example.

## Provenance labels
Author-created and expert-reviewed; sourced quotation; corpus-attested; generated candidate pending review. Never label generated material as corpus-attested. Record source and licence before reusing external corpus sentences.

## Output
Example inventory, coverage by rule, ambiguity and naturalness findings, provenance gaps, proposed replacements and regression set.

## Guardrails
Do not invent citations or corpus frequencies. Avoid presenting generated examples as authentic quotations. Do not overfit examples to a single dialect without labeling it.
