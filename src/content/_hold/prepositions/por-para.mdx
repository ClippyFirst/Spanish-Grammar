Українською обидва можуть перекладатися як «для», «за», «через», тому плутанина майже неминуча. Ключ: **para — ціль і призначення**, **por — причина, обмін і тривалість**.

## Одне речення

Para дивиться «вперед» (до мети), por дивиться «назад» (на причину) або «наскрізь» (обмін, тривалість).

## Para

- **Ціль / призначення:** *Estudio para trabajar en España.*
- **Отримувач:** *Un regalo para ti.*
- **Крайній термін:** *El informe es para mañana.*
- **Напрямок:** *Salgo para Madrid.*

## Por

- **Причина:** *Lo hago por ti.*
- **Обмін / ціна:** *Te doy 10 € por el libro.*
- **Тривалість:** *Por dos horas.*
- **Рух крізь:** *Camino por el parque.*
- **Від імені:** *Firmo por él.*

## Типові помилки україномовних

<Mistake
  bad="Salgo por mañana."
  good="Salgo para mañana."
  why="«На завтра» — крайній термін, тому para. «Por mañana» означало б «протягом завтрашнього дня»."
/>
<Mistake
  bad="Lo hago para ti, porque te quiero."
  good="Lo hago por ti, porque te quiero."
  why="Тут сенс «заради / через тебе» — причина, тому por. Para вживається для мети чи призначення."
/>

<Note kind="uk" title="Для україномовних">
  Українське «за» покриває обидва: «купити за гроші» (por), «працювати за ідею» (por). Але «для»
  у значенні мети завжди нормально перекладається як para: <em>regalo para ti</em> — «подарунок для тебе».
</Note>
