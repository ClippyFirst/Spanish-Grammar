Позиція прикметника в іспанській — не смак, а **граматика**: місце вирішує, чи це опис, чи оцінка, а іноді й сенс слова.

## Одне речення

Нейтральний опис — **після** (*un coche rojo*); суб'єктивна оцінка/кількість — **перед** (*una buena idea, muchos amigos*).

## Правило

- **Після (опис, тип, колір, форма):** *un coche rojo, una casa grande, el libro interesante.*
- **Перед (оцінка, кількість, порядок):** *buena idea, mal día, muchos amigos, primer capítulo, último tren.*
- **Присвійні/вказівні/числівники — завжди перед:** *mi casa, este libro, dos gatos* (це не прикметники-описи!).

## Пари зі зміною значення (вчити!)

- *un hombre **pobre*** (бідний, без грошей) / *un **pobre** hombre* (нещасний, шкода його)
- *un hombre **grande*** (великий зростом) / *un **gran** hombre* (велика людина)
- *un amigo **viejo*** (старий за віком) / *un **viejo** amigo* (давній друг)
- *una **nueva** casa* (інша, нова для мене) / *una casa **nueva*** (новозбудована)
- *el **propio** presidente* (сам президент) / *el presidente **propio*** (власний — рідко)

## Gran / buen / mal / primer — усічення!

- *grande → **gran*** перед одн.: *un gran día* (але *una grande casa* ❌)
- *bueno → **buen**: un buen amigo; malo → **mal**: un mal día*
- *primero → **primer**: el primer capítulo; tercero → **tercer***
