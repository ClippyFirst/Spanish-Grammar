Більшість прикметників лише «описують», але є група, де **позиція перед / після іменника** змінює значення — іноді радикально.

## Одне речення

*Un **gran** hombre* — «велика людина» (морально); *un hombre **grande*** — «великий чоловік» (розмір).

## Найважливіші пари

| Перед іменником | Після іменника |
|-----------------|-----------------|
| **gran** hombre (видатний) | hombre **grande** (великий на зріст) |
| **pobre** hombre (бідолашний) | hombre **pobre** (бідний) |
| **viejo** amigo (давній друг) | amigo **viejo** (старий друг) |
| **nueva** casa (інша/нова для мене) | casa **nueva** (нещодавно збудована) |
| **pura** agua (сама лише вода) | agua **pura** (чиста вода) |
| **cierto** problema (певний/якийсь) | problema **cierto** (достовірний) |
| **simple** soldado (звичайний) | soldado **simple** (наївний/простодушний) |
| **único** hijo (єдиний) | hijo **único** (унікальний у якомусь сенсі) |
| **antiguo** profesor (колишній) | profesor **antiguo** (старий/давній) |
| **diferentes** libros (різні/деякі) | libros **diferentes** (відмінні один від одного) |

## Граматичні нагадування

- *grande → gran* тільки перед іменником однини (чол. і жін.): *gran mujer*, але *grandes mujeres*.
- Узгодження роду/числа зберігається: *pobre mujer / mujeres pobres*.

<Note kind="uk" title="Для україномовних">
  В українській порядок прикметника зазвичай не створює таких усталених пар зі зміною значення. В іспанській тому корисно вчити ці випадки як **мінімальні пари**, але не перетворювати їх на жорстке правило: значення визначає конкретний прикметник і контекст.
</Note>

<Note kind="region" title="Регіональна нота">
  Значення пар стабільні скрізь. У деяких стилях і текстах прикметники перед іменником трапляються частіше, але це не універсальне правило для всіх слів.
</Note>
