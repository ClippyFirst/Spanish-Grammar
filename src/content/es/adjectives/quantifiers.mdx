Квантифікатори показують **кількість, обсяг або охоплення**: скільки чогось є, яку частину групи маємо на увазі або чи йдеться про кожного. Багато з них узгоджуються з іменником.

## Одне речення

*Much**a** gente, poc**os** libros, tod**a** la casa, algun**os** días, ningun**a** duda.*

## Список

| Форма | Приклад |
|-------|--------|
| mucho/a/os/as | *mucho tiempo, muchas ideas* |
| poco/a/os/as | *poca paciencia* |
| todo/a/os/as | *toda la noche, todos los días* |
| cada | *cada día* (незмінне) |
| algún / alguna / algunos / algunas | *algún problema* |
| ningún / ninguna | *ninguna duda* |
| varios/as | *varias veces* |
| bastante / suficiente | *bastante dinero* |

## Mucho ≠ muy

- *mucho* + іменник / після дієслова: *mucho trabajo; trabajo mucho*
- *muy* + adj/adv: *muy interesante*

## Algún / ningún

Перед чол. одниною — усічення: *algún libro, ningún problema* (не *alguno libro* у цій позиції).
