Ці слова пов'язані, але виконують різні синтаксичні функції.

## Muy

**Muy + прикметник або прислівник**:

*muy alto* — дуже високий;  
*muy bien* — дуже добре;  
*muy rápidamente* — дуже швидко.

*Muy* не узгоджується:

*muy alto / muy alta / muy altos / muy altas.*

## Mucho

**Mucho** має кілька ролей.

Перед іменником — детермінант/квантор:

*mucho tiempo*  
*mucha gente*  
*muchos libros*  
*muchas preguntas.*

Після дієслова — прислівник кількості:

*Trabajo mucho.*  
*Me gusta mucho.*

У цих функціях форма перед іменником узгоджується, після дієслова — ні.

## Tan

**Tan + прикметник/прислівник**, особливо в порівнянні:

*Es tan alto como su padre.*  
*Corre tan rápido como yo.*

Також *tan* може інтенсифікувати характеристику без явного *como*:

*No sabía que era tan difícil.*

## Tanto

Перед іменником:

*tanto tiempo, tanta gente, tantos libros, tantas preguntas.*

З дієсловом:

*Trabajo tanto.*  
*No hables tanto.*

У конструкції **tanto ... como**:

*Trabaja tanto como yo.*  
*Hay tanta gente como ayer.*

## Ключовий контраст

| Конструкція | Приклад |
|---|---|
| muy + adj/adv | *muy interesante* |
| mucho/a/os/as + noun | *muchos libros* |
| verbo + mucho | *estudio mucho* |
| tan + adj/adv | *tan interesante* |
| tanto/a/os/as + noun | *tantos libros* |
| verbo + tanto | *estudio tanto* |

## Для носія української мови учня

Корисна схема:

**якість → muy / tan**  
**кількість → mucho / tanto**

А потім перевіряйте синтаксичну позицію.
