У розмові іспанська рясніє **маркерами**, які структурують думку, а не «несуть» лексичне значення.

## Одне речення

***Bueno**, pues… **o sea**, no sé; **mira**, te explico; **a ver**…*

## Частотні

| Маркер | Функція |
|--------|--------|
| *bueno* | початок, пом’якшення, підсумок |
| *pues* | «тоді / ну»; наслідок; пауза |
| *o sea* | тобто / перефраз |
| *mira / oye* | привернути увагу |
| *a ver* | «давай подивимось» |
| *en plan* (Ісп., молодіжний) | «типу / в сенсі» |
| *este…* / *mmm* | пауза (Америка) |
| *che* | звертання (Аргентина/Уругвай) |

## Реєстр

У письмі й офіційній мові філери майже зникають; їх замінюють конектори (*es decir, por tanto*).

## Для україномовних

<Note kind="uk" title="Для україномовних">
  Не калькуйте «ну / типу / короче» дослівно.
  *O sea* ≈ «тобто»; *pues* ≈ «ну / тоді»; *bueno* ≈ «добре / отже».
</Note>

<Note kind="region" title="Регіональна нота">
  *En plan* — сильніше Іспанія; *che* — Cono Sur; *pues* універсальний.
</Note>
