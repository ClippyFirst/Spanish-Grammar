Це **не** словник і **не** заміна граматиці. Коротка вибірка слів, які **виглядають** знайомими й підштовхують до неправильного значення.

## Швидка довідка

| Схоже на | Значення ES | Якщо хотіли сказати |
|----------|-------------|---------------------|
| *actual* | нинішній | актуальний → *relevante, de actualidad* |
| *éxito* | успіх | вихід → *salida* |
| *librería* | книгарня | бібліотека → *biblioteca* |
| *embarazada* | вагітна | збентежена → *avergonzada / confundida* |
| *constipado* | з застудою | (EN false friend: не «закрепочений») |
| *sensible* | чутливий | розсудливий → *razonable, sensato* |
| *realizar* | здійснити | зрозуміти → *darse cuenta* |
| *carpeta* | папка (файл) | килим → *alfombra* (пор. EN carpet) |
| *decepción* | розчарування | обман → *engaño* |
| *largo* | довгий | широкий → *ancho* |

## Навіщо в граматичному довіднику

Лексична калька часто тягне **граматичну**: не той прийменник, не той час, не та конструкція. Якщо слово «підозріло міжнародне» — перевірте значення, перш ніж будувати фразу.

Див. також [інтерференції](/es/fundamentals/ua-interference/).

## Приклади в реченні

- *El problema **actual*** — нинішня проблема (не обов'язково «актуальна тема»).
- *La película fue un **éxito*** — успіх (не «вихід з залу»).
- *Está **embarazada*** — вона вагітна.
