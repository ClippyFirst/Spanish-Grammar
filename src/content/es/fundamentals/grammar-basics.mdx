Короткий словник понять для решти довідника. Без нього легко плутати «рід» і «стать» або не бачити узгодження з артиклем.

## Швидка довідка

| Поняття | Іспанською | Суть |
|---------|------------|------|
| Морфема | *morfema* | мінімальна значуща або функціональна частина (*habl- / -amos*) |
| Основа / закінчення | *raíz / desinencia* | лексика + граматика |
| Узгодження | *concordancia* | рід/число (і особа в дієслові) |
| Рід | *género* | чоловічий / жіночий |
| Число | *número* | однина / множина |
| Особа | *persona* | 1 / 2 / 3 |

## Слово і морфема

- *hablamos* = *habl-* + *-amos*
- *casas* = *casa* + *-s*
- Артикль *el/la* — **окреме слово**, не закінчення іменника

## Змінні і незмінні частини мови

**Змінні:** іменник, прикметник, дієслово, артикль, частина займенників.

**Незмінні:** прислівник, прийменник, сполучник, вигук.

- *rápido* (прикм.) → *rápida, rápidos*
- *rápidamente* (присл.) — без роду/числа

## Рід, число, особа, узгодження

- *la casa blanca* — усе жіночий однина
- *los libros están* — множина в підметі → множина в дієслові
- Особа в закінченні дієслова дозволяє **опускати** підмет: *Hablo español.*

## Граматичний рід vs природна стать

- *el niño / la niña* — збіг зі статтю людини
- *la persona, la víctima, el bebé* — граматичний рід **не** дорівнює біології автоматично
- *el problema, la mano* — рід за формою/традицією

Докладно: [рід](/es/nouns/genero/), [винятки](/es/nouns/gender-exceptions/).

## Скелет речення

Підмет + присудок + (прямий / непрямий додаток) + (обставини). Порядок гнучкіший за англійську, але для багатьох нейтральних речень природним орієнтиром є SVO, але іспанський порядок слів значно варіативніший.

Див. [порядок слів](/es/sentence-structure/word-order/).

<Note kind="uk" title="Для україномовних">
  В українській є рід і узгодження, але **нема артикля**.
  Іспанська додає обов'язковий вибір el/la/un/una/нуль майже в кожній іменниковій групі.
</Note>

<Note kind="region" title="Регіональна нота">
  Категорії роду/числа/особи спільні для всього іспаномовного світу.
</Note>
