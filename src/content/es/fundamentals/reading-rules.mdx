Іспанська орфографія відносно прозора: більшість літер читаються стабільно. Нижче — місця, де без правила легко помилитись.

## Швидка довідка

| Написання | Читання (загальне) |
|-----------|-------------------|
| *ca, co, cu / que, qui* | [k] |
| *ce, ci / z* | [s] або [θ] (див. seseo) |
| *ga, go, gu / gue, gui* | [g] |
| *ge, gi / j* | [x] |
| *güe, güi* | [gwe], [gwi] — **ü** чути |
| *r-* / *-rr-* / *n, r + r* | сильне [r] |
| *-r-* між голосними | [ɾ] |
| *h* | Ø (німе) |

## C і G — «тверді / м'які» позиції

**C**

- *ca, co, cu* → [k]: *casa, cosa*
- *ce, ci* → [s]/[θ]: *cena, cine*
- Щоб зберегти [k] перед *e/i*: **qu** — *que, qui* (*queso, quiso*), ніколи ~~qe~~.

**G**

- *ga, go, gu* → [g]: *gato, goma*
- *ge, gi* → [x]: *gente, girar*
- Щоб зберегти [g] перед *e/i*: **gue, gui** — *guerra, guitarra*
- Щоб чути **u**: **güe, güi** — *pingüe, lingüista, vergüenza*

## Q

Майже лише в *que, qui* (+ *qü* у рідкісних запозиченнях). Звук [k].

## R / RR

- *Rosa, enredo, alrededor* — сильне r
- *caro* vs *carro*; *pero* vs *perro*

## Y, LL, B, V, X

- **y** на початку / як приголосний ≈ *ll* (yeísmo); як сполучник *y* («і») — [i]/[j]
- **b** і **v** у більшості діалектів **не** розрізняють за дзвінкістю так, як в українській «б/в»; орфографію вчать окремо → [b/v](/es/spelling/b-v/)
- **x** часто передає [ks] у словах на кшталт *éxito*, але має інші реалізації в окремих словах і позиціях; *México* — відомий приклад.

## Зв'язок з дієвідміною

Чергування *c/qu, g/gu, z/c* у формах дієслів: *buscar → busqué, pagar → pagué, cruzar → crucé*.

Див. [орфографічні зміни](/es/verbs/orthographic-changes/).

<Note kind="uk" title="Для україномовних">
  Українська «ге/гі» не збігається з іспанським розподілом g/j.
  Таблиця ca/que/ga/gue — вивчити як систему, не по одній букві.
</Note>

<Note kind="region" title="Регіональна нота">
  Правила читання спільні; відрізняється реалізація c/z/s і ll/y.
</Note>
