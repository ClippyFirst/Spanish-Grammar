Це **не** список «сорому», а навігатор: куди в довіднику йти, коли калька з української (або через англійську) підштовхує до помилки.

## Швидка карта

| Зона | Типовий збій | Куди в довідник |
|------|--------------|----------------|
| Артиклі | нуль скрізь або *el* «на всяк випадок» | [нульовий](/es/articles/zero-article/), [el vs un](/es/articles/definite-vs-indefinite/) |
| Наявність | *No tengo un coche* замість *No tengo coche* | [zero-article](/es/articles/zero-article/) |
| Ser / estar / hay | *Es en Madrid* / *Hay el libro* | [ser-estar](/es/verbs/ser-estar/), [hay vs estar](/es/sentence-structure/hay-vs-estar/) |
| Минулі часи | один «минулий» на все | [indefinido vs imperfecto](/es/tenses/preterito-vs-imperfecto/) |
| Subjuntivo | indicativo після *quiero que* | [тригери](/es/moods/subjunctive-triggers/) |
| Por / para | взаємозаміна | [por-para](/es/prepositions/por-para/) |
| Gustar | *Yo gusto café* | [gustar](/es/verbs/gustar/) |
| Клітики | порядок і *se lo* | [подвійні](/es/pronouns/double-object-pronouns/) |
| Заперечення | без подвійного *no… nunca* | [negation](/es/sentence-structure/negation/) |
| Частини тіла | *mi cabeza duele* | [body-parts](/es/pronouns/body-parts-possession/) |
| «Do»-підсилення | *Yo hago quiero* | [emphasis](/es/sentence-structure/emphasis-polarity-focus/) |
| Час «тому / уже як» | *Vivo aquí hace dos años* | [hace / desde hace](/es/prepositions/hace-desde-hace/) |

## Чому саме ці зони

1. **Артиклів в українській немає** — уся система el/un/нуль будується з нуля.
2. **Один минулий** у розмовній практиці UA vs кілька іспанських.
3. **Інша модель «подобається»** (дативний підмет у ES).
4. **Клітики** як обов'язкові маленькі слова перед дієсловом.
5. Кальки з **англійської** (*do*, *I am agree* → *estoy de acuerdo*).

## Як користуватись цією сторінкою

1. Знайдіть зону в таблиці.
2. Відкрийте цільову тему.
3. Порівняйте мінімальні пари, не лише «правило в одному рядку».
