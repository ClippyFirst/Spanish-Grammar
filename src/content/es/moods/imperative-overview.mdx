Імператив має **окремі** форми для ствердження (tú/vosotros) і використовує **presente de subjuntivo** для заперечення та для usted/ustedes.

## Одне речення

***Habla!** / ***No hables.*** / ***Hable** usted.* / ***Hablad!** / ***No hablen.***

## Парадигма (hablar)

| Особа | Ствердження | Заперечення |
|-------|-------------|-------------|
| tú | habla | no hables |
| usted | hable | no hable |
| nosotros | hablemos | no hablemos |
| vosotros | hablad | no habléis |
| ustedes | hablen | no hablen |

## Неправильні tú (ствердження)

*di, haz, ve, pon, sal, sé, ten, ven* (decir, hacer, ir, poner, salir, ser, tener, venir).

## Займенники

- Ствердження: **після**, разом: *dámelo, hazlo*
- Заперечення: **перед**: *no me lo des, no lo hagas*
