Дві конструкції, без яких важко звучати природно: **ojalá** (хай би / добре б) і **como si** (неначе / ніби).

## Швидка довідка

| Конструкція | Спосіб | Приклад |
|-------------|--------|---------|
| *Ojalá* + presente subj. | бажане можливе | *Ojalá venga.* — Хай би прийшов. |
| *Ojalá* + imperfecto subj. | бажане малоймовірне / у минулому | *Ojalá viniera.* — Шкода, що не… / добре б прийшов. |
| *Como si* + imperfecto subj. | нереальна аналогія (тепер) | *Habla como si fuera el jefe.* |
| *Como si* + pluscuamperfecto subj. | нереальна аналогія (минуле) | *Actuó como si no hubiera pasado nada.* |

## 1. *Ojalá*

Походить від арабського побажання; зараз — «добре б / хай би».

### З presente de subjuntivo

Бажання щодо **теперішнього / майбутнього**, яке вважають можливим:

- *Ojalá no llueva mañana.* — Добре б завтра не дощило.
- *Ojalá apruebes el examen.* — Хай би склав іспит.
- *Ojalá que vengas.* — (*que* опційне) Хай би ти прийшов.

### З imperfecto de subjuntivo

Бажання **малоймовірне**, жаль про теперішнє / минуле:

- *Ojalá tuviera más tiempo.* — Шкода, що немає більше часу / добре б мав.
- *Ojalá no hubiera dicho eso.* — Краще б цього не казав. (часто + pluscuamperfecto subj.)

## 2. *Como si*

Завжди + **subjuntivo** (imperfecto або pluscuamperfecto) — бо ситуація **нереальна**.

- *Habla **como si fuera** el dueño.* — Говорить, начебто він власник.
- *Me miró **como si no me conociera**.* — Подивився, ніби не знає мене.
- *Gastan **como si fueran** millonarios.* — Витрачають, ніби мільйонери.

Минуле + pluscuamperfecto subj.:

- *Siguió hablando **como si no hubiera oído** nada.* — Продовжував говорити, ніби нічого не чув.

**Не** *como si + indicativo* у цих значеннях:

- ~~*como si es*~~ → *como si **fuera***

## Типові помилки україномовних

<Mistake
  bad="Ojalá viene."
  good="Ojalá venga."
  why="Після ojalá — subjuntivo, не indicativo."
/>

<Mistake
  bad="Habla como si es el jefe."
  good="Habla como si fuera el jefe."
  why="Como si + imperfecto de subjuntivo (нереальне порівняння)."
/>

<Mistake
  bad="Ojalá que tendré suerte."
  good="Ojalá tenga suerte."
  why="Не futuro de indicativo після ojalá."
/>

<Note kind="uk" title="Для україномовних">
  «Добре б…» / «хай би…» → *ojalá* + subjuntivo.
  «Ніби / начебто / мов» у нереальній аналогії → *como si* + imperfecto subj.,
  не «як якщо є» з теперішнім indicativo.
</Note>

<Note kind="region" title="Регіональна нота">
  Ojalá і como si — загальноіспанські. У розмові *ojalá* дуже частотне в усьому іспаномовному світі.
</Note>
