Це **швидка карта**, а не друга повна стаття про subjuntivo. Для пояснення причин, варіативності та складніших випадків переходьте до [детального розбору тригерів](/es/moods/subjunctive-triggers/).

## Карта контекстів

| Контекст | Типова модель | Приклад |
|---|---|---|
| Воля / прохання | *querer que + subj.* | *Quiero que vengas.* |
| Емоція / оцінка | *es importante que + subj.* | *Es importante que estudies.* |
| Сумнів / заперечення | *dudar que + subj.* | *Dudo que tenga razón.* |
| Мета | *para que + subj.* | *Te lo explico para que entiendas.* |
| Майбутній час у підрядному | *cuando + subj.* | *Cuando llegues, llama.* |
| Гіпотетична поступка | *aunque + subj.* | *Aunque sea difícil, lo intentaré.* |
| Невизначений референт | *que + subj.* | *Busco un libro que sea interesante.* |
| Побажання | *ojalá + subj.* | *Ojalá llueva.* |

## Коли індикатив

Не сприймайте список як механічний набір слів. Та сама лексема може вести до різного способу залежно від конструкції:

- *Creo que está bien.*
- *No creo que esté bien.*
- *Sé que viene.*
- *Busco a alguien que sabe la respuesta.* / *Busco a alguien que sepa la respuesta.*

Для повного пояснення межі між indicativo і subjuntivo див. [коли subjuntivo не вживається](/es/moods/when-not-subjunctive/) та [presente de subjuntivo](/es/moods/subjuntivo-presente/).

## Швидка перевірка

Перед вибором способу визначте **структуру**, а не лише головне дієслово:

1. Це твердження про факт?
2. Це бажання, оцінка, емоція або сумнів?
3. Це мета, умова, часова чи допустова конструкція?
4. Референт уже визначений чи лише шукається?
5. Чи є окремий спеціальний тригер на кшталт *ojalá*?

## Важливо для україномовних

Subjuntivo не означає просто «я не впевнений». Він може бути структурно зумовлений метою, часом, допустовістю, невизначеним референтом та іншими конструкціями.
