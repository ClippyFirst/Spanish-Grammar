Більшість множин утворюється за регулярними правилами **-s / -es**, але деякі форми потребують орфографічної або наголосної зміни.

## z → c

Перед *-es*:

- *lápiz → lápices*;
- *luz → luces*;
- *voz → voces*;
- *pez → peces*;
- *raíz → raíces*.

Це орфографічне правило, а не «неправильна» множина в лексичному сенсі.

## Наголос

У деяких словах при додаванні *-es* змінюється наголосна структура й виникає/зберігається тільда:

- *examen → exámenes*;
- *joven → jóvenes*;
- *régimen → regímenes*;
- *carácter → caracteres*.

Окремо запам'ятайте, що не кожне слово на *-n* поводиться однаково.

## Незмінні форми

Частина слів на -s та -x не змінюється:

- *el lunes → los lunes*;
- *la crisis → las crisis*;
- *el tórax → los tórax*.

У таких випадках число видно з детермінанта та узгодження:

*el lunes* / *los lunes*.

## Запозичення

Для деяких запозичень можливі конкуруючі моделі:

*club → clubs / clubes*  
*chalet → chalets*.

Тому не варто робити з одного слова універсальне правило для всіх іншомовних іменників.

## Для носія української мови учня

Не називайте всі ці випадки «винятками». Корисніше розрізняти:

1. регулярну морфологію;
2. орфографічну адаптацію (*z → c*);
3. правила наголосу;
4. незмінні форми;
5. конкуруючі норми для запозичень.
