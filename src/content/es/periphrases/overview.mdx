Перифраза = допоміжне дієслово + інфінітив / герундій / participio з новим аспектуальним значенням.

## Одне речення

*Voy a estudiar; Tengo que ir; Estoy trabajando; Acabo de llegar; Vuelvo a intentarlo; Sigo buscando.*

## Карта

| Перифраза | Значення | Приклад |
|-----------|----------|--------|
| **ir a + INF** | майбутнє близьке / намір | *Voy a llamar.* |
| **tener que + INF** | обов’язок | *Tengo que terminar.* |
| **hay que + INF** | треба (безособово) | *Hay que estudiar.* |
| **estar + gerundio** | процес зараз | *Está lloviendo.* |
| **seguir / continuar + gerundio** | продовження | *Sigue trabajando.* |
| **acabar de + INF** | щойно | *Acabo de llegar.* |
| **volver a + INF** | знову | *Volvió a llamar.* |
| **dejar de + INF** | перестати | *Dejó de fumar.* |
| **ponerse a + INF** | почати (раптово) | *Se puso a llorar.* |
| **llevar + gerundio** | «вже X часу як» | *Llevo dos horas esperando.* |

## Типові помилки україномовних

<Mistake
  bad="Tengo de ir."
  good="Tengo que ir."
  why="Tener **que**, не de."
/>

<Mistake
  bad="Acabo llegar."
  good="Acabo de llegar."
  why="Acabar **de** + INF."
/>

<Note kind="uk" title="Для україномовних">
  Вчіть перифрази блоками з прийменником: acabar **de**, tener **que**, volver **a**.
</Note>

<Note kind="region" title="Регіональна нота">
  Набір спільний. Ir a + INF дуже частотний в Америці як «майбутнє».
</Note>
