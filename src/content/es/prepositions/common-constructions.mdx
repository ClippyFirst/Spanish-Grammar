Багато значень передаються не «голосним» дієсловом, а **стійкою парою дієслово/іменник + прийменник**. Їх краще запам’ятовувати цілими блоками.

## Одне речення

*Tengo ganas **de** viajar* — «Мені хочеться подорожувати»; *Dejé **de** fumar* — «Я кинув палити».

## Дієслово + прийменник (найчастотніші)

| Конструкція | Значення | Приклад |
|-------------|----------|--------|
| *dejar de* + inf | перестати | *Dejó de llover.* |
| *acabar de* + inf | щойно зробити | *Acabo de llegar.* |
| *volver a* + inf | знову | *Volvió a llamar.* |
| *empezar a / ponerse a* | почати | *Empezó a llover.* |
| *aprender a* | навчитися | *Aprendí a nadar.* |
| *soñar con* | мріяти про | *Sueño con viajar.* |
| *casarse con* | одружитися з | *Se casó con Ana.* |
| *pensar en* | думати про | *Pienso en ti.* |
| *consistir en* | полягати в | *Consiste en practicar.* |
| *depender de* | залежати від | *Depende del tiempo.* |
| *enamorarse de* | закохатися в | *Se enamoró de ella.* |
| *acordarse de* | згадувати | *¿Te acuerdas de mí?* |
| *olvidarse de* | забувати | *Me olvidé de la cita.* |

## Іменник / прикметник + прийменник

- *ganas de* — *Tengo ganas de café.*
- *miedo a / de* — *Tiene miedo a volar.*
- *derecho a* — *Tienes derecho a saberlo.*
- *fácil / difícil de* — *Es fácil de entender.*
- *lleno de* — *La sala está llena de gente.*
- *cerca de / lejos de* — *Vivo cerca del centro.*

## Por / para в стійких виразах

- *por ejemplo, por fin, por favor, por supuesto*
- *para siempre, para nada, para colmo*

(Детальніше — на сторінці por/para.)

<Note kind="uk" title="Для україномовних">
  Українські «мріяти про», «одружитися з», «перестати» не підказують прийменник.
  Ці пари треба вчити як готові «цеглинки» — особливо soñar con, casarse con, ganas de, dejar de.
</Note>

<Note kind="region" title="Регіональна нота">
  Більшість конструкцій спільні. Відмінності точкові: *pensar en* скрізь;
  у деяких зонах *pensar de* зі значенням «мати думку про».
</Note>
