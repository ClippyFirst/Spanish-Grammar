Українське «тому», «вже … як», «з … року» розведені іспанською по різних схемах. Найчастіша плутанина — *hace* vs *desde hace*.

## Швидка довідка

| Сенс | Схема | Приклад |
|------|-------|---------|
| «N тому» (відлік назад) | **hace** + тривалість | *Hace dos años me mudé.* — Два роки **тому** я переїхав. |
| «уже N як» (триває досі) | **desde hace** + тривалість | *Vivo aquí **desde hace** dos años.* — Живу тут **уже** два роки. |
| «з моменту / дати» | **desde** + точка | *Desde 2020 vivo aquí.* — З 2020 живу тут. |
| «уже N як» (альтернатива) | **hace** + N + **que** + presente | *Hace dos años **que** vivo aquí.* |

## 1. *Hace* + тривалість — «тому»

Подія **в минулому**, відлік від зараз назад:

- *Hace una semana salí de viaje.* — Тиждень тому поїхав.
- *La vi hace tres días.* — Бачив її три дні тому.

Форма дієслова залежить від часової перспективи; сама конструкція *hace + тривалість* не означає «дія триває стільки часу». Порівняйте *Hace dos años me mudé* і *Hace dos años que vivo aquí*.

## 2. *Desde hace* + тривалість — «уже … як»

Стан / дія **триває дотепер**:

- *Trabajo aquí desde hace cinco años.* — Працюю тут уже п'ять років.
- *La conozco desde hace poco.* — Знаю її недавно (уже якийсь час).

У сучасній іспанській *desde hace* часто поєднується з *presente*, коли ситуація почалася раніше й актуальна досі, але це не правило для всіх контекстів: *Desde hacía años vivía allí* також нормативне.

## 3. *Hace* + N + *que* + presente

Той самий сенс, що *desde hace*:

- *Hace cinco años **que** trabajo aquí.* ≈ *Trabajo aquí **desde hace** cinco años.*

## 4. *Desde* + точка в часі

- *Desde el lunes.* — З понеділка.
- *Desde 2019.* — З 2019 року.
- *Desde que llegué.* — Відтоді, як приїхав.

**Не** *desde hace 2019* — після *desde hace* лише **тривалість** (*dos años*), не дата.

## Мінімальні пари

| | |
|--|--|
| *Hace dos años me mudé.* — Переїхав **два роки тому** (завершена дія). | *Vivo aquí desde hace dos años.* — Живу тут **уже два роки** (триває). |
| *Desde 2020.* — З 2020 (точка). | *Desde hace tres años.* — Уже три роки (тривалість). |

<Note kind="uk" title="Для україномовних">
  «Два роки тому» → *hace dos años* + минулий час.
  «Уже два роки (як) живу» → *desde hace dos años* / *hace dos años que* + теперішній.
  Не змішуйте ці дві схеми.
</Note>

<Note kind="region" title="Регіональна нота">
  Схеми загальноіспанські. У розмові *hace… que* дуже частотне скрізь.
</Note>


## Тривалість до референтного моменту

Для дії, яка почалася в минулому й **досі триває**, іспанська часто використовує:

- **llevar + тривалість + gerundio:** *Llevo tres años estudiando español.*
- **hacer + тривалість + que + presente:** *Hace tres años que estudio español.*
- **desde hace + тривалість + presente:** *Estudio español desde hace tres años.*

Усі три можуть описувати тривалість до теперішнього моменту, але по-різному організовують інформацію. *Llevar + тривалість + gerundio* особливо виразно подає накопичену тривалість дії; *desde hace* подає відтинок від початку до референтного моменту; *hace... que* оформлює той самий часовий зв’язок через окрему конструкцію.

Не робіть із *hace... que* формулу лише для теперішнього часу: часова форма залежить від контексту. Наприклад, *Hace tres años que vivía allí cuando nos conocimos* відносить тривалість до минулого референтного моменту.
