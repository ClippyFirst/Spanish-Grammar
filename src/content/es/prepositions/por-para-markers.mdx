Por і para — прийменники з кількома пов'язаними значеннями; ця сторінка дає орієнтири, а не повний перелік уживань. Нижче — навчальні маркери й мінімальні пари, але не «формула», яка автоматично покриває всі контексти. Значення визначається конструкцією та відношенням між її компонентами.

## Одне речення

**Lo hice por ti** (причина / заради); **Lo hice para ti** (отримувач / тобі).

## Por — типові значення

| Значення | Приклад |
|----------|--------|
| Причина | *Por el tráfico llegué tarde.* |
| Шлях / місце «через» | *Pasamos por el centro.* |
| Обмін / ціна | *Lo compré por 10 euros.* |
| Тривалість (частіше в американській іспанській; також засвідчено в європейській) | *Estudié por tres horas.* |
| «Заради» / на користь | *Lo hago por mi familia.* |
| Безособові формули | *por ejemplo, por favor, por fin* |

## Para — типові значення

| Значення | Приклад |
|----------|--------|
| Мета | *Estudio para aprender.* |
| Напрямок / пункт призначення | *Salgo para Madrid.* |
| Дедлайн | *Para el lunes.* |
| Отримувач | *Este regalo es para ti.* |
| «З огляду на» (оцінка) | *Para ser principiante, habla bien.* |

<Note kind="uk" title="Для українськомовного читача">
  Українське «для / через / заради / на» не ділиться один-в-один.
  Питання: це мета/отримувач/дедлайн (para) чи причина/шлях/обмін/тривалість (por)?
</Note>

<Note kind="region" title="Регіональна нота">
  NGLE § 29.8p зазначає, що *por* із кількісним виразом тривалості частіше вживається в американській іспанській, ніж у європейській, хоча засвідчений в обох. Це конкретне спостереження не слід поширювати на всі конструкції з *por* і *para*.
</Note>
