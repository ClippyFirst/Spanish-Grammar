**Por*** і para** не мають одного сталого українського перекладу. Обидва можуть відповідати словам «за», «для», «через», «на», а в окремих конструкціях український переклад узагалі не містить прийменника. Тому корисніше визначати не українське слово, а * **відношення, яке створює вся іспанська конструкція***.

## Швидка карта

| Значення | Типовий вибір | Приклад |
|---|---|---|
| мета / призначення | **para** | *Estudio para trabajar.* |
| адресат | **para** | *Es para María.* |
| крайній строк | **para** | *Es para mañana.* |
| напрямок / пункт призначення | **para** | *Salimos para Madrid.* |
| причина / мотив | **por** | *Lo hice por ti.* |
| обмін / ціна | **por** | *Lo compré por 20 euros.* |
| маршрут / простір | **por** | *Paseamos por el centro.* |
| тривалість | **por** | *Trabajé por tres horas.* |
| засіб у низці конструкцій | **por** | *Te lo envío por correo.* |
| агент пасиву | **por** | *Fue escrito por Ana.* |

Це карта найважливіших зон, а не повний список усіх уживань.

## Para: мета, адресат, строк і напрямок

### Мета

*Estudio español para trabajar en España.*  
Я вчу іспанську, щоб працювати в Іспанії.

Перед іменником:

*Esto sirve para niños.*  
Це призначене для дітей.

Перед підрядним реченням:

*Lo hago para que puedas descansar.*  
Я роблю це, щоб ти міг відпочити.

Порівняйте:

*Estudio para trabajar.*  
Я вчуся, щоб працювати.

*Estudio para que mis hijos puedan estudiar.*  
Я вчуся, щоб мої діти могли вчитися.

Para + infinitivo і para que + особова форма розрізняють тип синтаксичної конструкції; не варто перетворювати це на абсолютне правило лише про «однаковий / різний підмет».

### Адресат

*Este regalo es para ti.*  
Цей подарунок для тебе.

Тут *para* позначає особу, для якої щось призначене. Це інше відношення, ніж у *Lo hice por ti*, де *por* може позначати мотив або причину.

### Крайній строк

*Necesito el informe para mañana.*  
Мені потрібен звіт на завтра.

*Para el lunes* задає строк, до якого очікується результат. Це не те саме, що *desde el lunes*, де йдеться про початкову точку.

### Напрямок

*Salimos para Madrid.*  
Ми вирушаємо до Мадрида.

У контекстах руху **para** підкреслює напрямок або пункт призначення. Для базового просторового контрасту див. також *a* у *Voy a Madrid* та *por* у *Paso por Madrid*.

## Por: причина, шлях, обмін, тривалість та засіб

### Причина / мотив

*Lo hice por ti.*  
Я зробив це заради тебе / через тебе як мотив.

*Gracias por venir.*  
Дякую, що прийшов.

У *gracias por* *por* входить до сталої конструкції подяки за підставу або дію.

### Обмін і ціна

*Pagué veinte euros por el libro.*  
Я заплатив двадцять євро за книжку.

*Te cambio mi libro por el tuyo.*  
Я обміняю свою книжку на твою.

### Простір і маршрут

*Paseamos por el parque.*  
Ми гуляємо парком.

*Pasamos por el centro.*  
Ми проходимо через центр.

Тут *por* позначає простір або маршрут, через який проходить дія.

### Тривалість

*Trabajé por tres horas.*  
Я працював три години.

Для тривалості існують також інші моделі, зокрема *durante tres horas*. Тому не вчіть *por = тривалість* як універсальне правило: конкретна конструкція визначає природний вибір.

### Засіб / канал

*Te envío el documento por correo.*  
Я надсилаю документ електронною поштою / поштою — залежно від контексту.

*Hablamos por teléfono.*  
Ми розмовляємо телефоном.

### Агент пасивної конструкції

*La novela fue escrita por García Márquez.*  
Роман був написаний Гарсією Маркесом.

Тут *por* позначає агента пасивної конструкції, а не причину.

## Мета vs причина

Estudio para aprobar el examen.  
Я вчуся, **щоб** скласти іспит.

Estudio por el examen.  
Я вчуся **через / з приводу** іспиту.

У першому реченні скласти іспит є ***метою. У другому іспит пов'язаний із навчанням як * **причина або підстава***, а точна інтерпретація залежить від контексту. Це важливіше за механічне правило «para = щоб, por = через».

## Конструкції, які треба вчити цілісно

Деякі випадки не варто намагатися вивести з одного універсального правила:

- *por la mañana* — уранці;
- *por eso* — тому / через це;
- *por ejemplo* — наприклад;
- *por lo menos* — принаймні;
- *para siempre* — назавжди;
- *para mí* — для мене / на мою думку;
- *por mí* — через мене / заради мене / з мого боку — залежно від контексту.

Це не «винятки», а звичайна полісемія прийменників і сталі конструкції.

## Для носія української мови учня

Українські **за, для, через, на, по*** перекриваються з кількома іспанськими прийменниками. Тому не перекладайте прийменник окремо. Спочатку визначте, що саме виражає вся конструкція: мету, адресата, причину, маршрут, обмін, строк, засіб чи інше відношення* **; лише після цього перевіряйте, чи потрібні **por* або *para*.

## Регіональна варіативність

Основна система *por/para* спільна для іспаномовного світу. Окремі сталі конструкції можуть відрізнятися за частотністю або стилістичними вподобаннями, але це не скасовує базових семантичних контрастів.
