Іспанська може виражати два об'єкти одночасно займенниками: один позначає **непрямий додаток (OI), інший — прямий (OD)**.

*Me lo dio.*  
Він/вона дав(ла) мені це.

Тут *me* = одержувач, *lo* = те, що передали.

## Порядок: OI + OD

Типова послідовність:

**me / te / le / nos / os / les + lo / la / los / las**

Наприклад:

*Te la envié.* — Я надіслав тобі її.  
*Nos los explicaron.* — Нам їх пояснили.

Порядок не залежить від того, який займенник логічно «важливіший» в українській.

## le / les → se

Послідовність *le + lo*, *les + la* тощо не використовується. Перед займенником прямого додатка *le/les* переходить у *se*:

*Le di el libro.* → *Se lo di.*  
Я дав йому книжку → Я дав йому її.

*Les expliqué la situación.* → *Se la expliqué.*

Це не зворотне *se*. Тут *se* замінює *le/les* і зберігає функцію непрямого додатка в цій конструкції.

## Не плутайте значення se

*Se lava.* — Він/вона миється. → зворотне *se*.

*Se lo di.* — Я дав йому/їй це. → *se* замість *le/les* перед прямим додатком.

*Se venden libros.* — Продаються книжки. → пасивна/аналогічна конструкція з *se*.

Форма одна, граматичні функції різні.

## Позиція

Перед спряженою формою:

*Se lo doy.*

З інфінітивом можливі два варіанти, залежно від конструкції:

*Quiero dárselo.*  
*Se lo quiero dar.*

З герундієм:

*Estoy explicándoselo.*

Зі стверджувальним наказовим способом:

*Dáselo.* — Дай йому/їй це.

З заперечним наказовим:

*No se lo des.* — Не давай йому/їй цього.

При приєднанні займенників наголос може вимагати письмової тильди: *dáselo, explícamelo, diciéndoselo*.

## Для українськомовного читача

Українське «я дав йому це» дозволяє окремо вимовити два займенники. В іспанській їхня **послідовність морфологічно закріплена**.

Корисно вчити не окреме *se*, а конструкцію:

> **se lo / se la / se los / se las** = непрямий адресат + прямий об'єкт.
