Базовий порядок — **SVO**, але питання, клітики й прикметники гнучкіші.

## Одне речення

*María compra pan; ¿Qué compra María?; Lo compra; Una casa **blanca** / **blanca** casa (рідко, поетично).*

## Схеми

1. **Розповідь:** Підмет + дієслово + додатки — *Juan lee el libro.*
2. **Питання:** питальне слово + дієслово + підмет — *¿Qué lee Juan?*
3. **Клітики:** перед спряженим / після інфінітива-герундія-ствердж. імператива — див. [позиція займенників](/es/pronouns/object-pronoun-placement/).
4. **Прикметник:** зазвичай після іменника; перед — суб’єктивна оцінка / сталі вирази — див. [позиція](/es/adjectives/adjective-position/).

## Гнучкість

Іспанська дозволяє інверсію для фокусу: *Llegó Juan* (акцент на приході). Не калькуйте жорсткий англійський порядок.
