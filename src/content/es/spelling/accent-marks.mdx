Іспанський наголос визначають **три правила** — знаючи їх, ви ставите тільду без словника.

## Одне речення

Закінчення на голосну/n/s → наголос на **передостанньому** (*libro*); інакше → на **останньому** (*ciudad*); порушення правила → **тільда** (*lápiz, café*).

## Три правила

- **Agudas** (наголос на останньому): на приголосну (крім n/s) — *ciudad, papel*. Тільда, якщо закінчення голосна/n/s і наголос останній: *café, jamón, estás*.
- **Llanas** (на передостанньому): на голосну/n/s — *libro, casa, comen*. Тільда, якщо закінчення інша приголосна: *lápiz, árbol*.
- **Esdrújulas / sobresdrújulas** (на 3-му / 4-му з кінця): **завжди** тільда — *música, dámelo*.

## Діакритична тільда (розрізнення слів)

| З тільдою | Без |
|-----------|-----|
| *sí* (так) | *si* (якщо) |
| *tú* (ти) | *tu* (твій) |
| *él* (він) | *el* (артикль) |
| *mí* (мене) | *mi* (мій) |
| *té* (чай) | *te* (тобі) |
| *dé* (від dar) | *de* (прийменник) |
| *sé* (знаю / будь) | *se* (займенник) |
| *más* (більше) | *mas* (але, книжне) |
| *qué, cómo, cuándo, dónde, quién…* у питаннях/окликах | *que, como, cuando…* у підрядних |

## sólo / solo і aún / aun (норма RAE)

**Сучасна норма RAE:** тільда в *sólo* (лише) **не обов'язкова**, якщо немає двозначності; рекомендують *solo* без тільди. *Sólo* з тільдою дозволене для розрізнення з *solo* (самотній).

- *Solo quiero agua.* — Лише хочу води.
- *Está solo.* — Він сам.

**aún** (ще / досі) — з тільдою, коли = *todavía*.
**aun** (навіть) — без тільди: *aun así* — навіть так.

- *Aún no ha llegado.* — Ще не приїхав.
- *Aun los niños lo saben.* — Навіть діти це знають.

## Хіатус і тільда

Наголошена слабка голосна поруч із сильною → тільда і хіатус: *país, río, baúl*. Див. [дифтонги і хіатус](/es/spelling/diphthongs-hiatus/).

## Типові помилки

  bad="Si, quiero."
  good="Sí, quiero."
  why="Стверджувальне sí — з тільдою."

<Mistake
  bad="Aun no sé." (у значенні «ще»)

/>

<Note kind="uk" title="Для україномовних">

  Запам'ятайте пари sí/si, tú/tu, aún/aun.
</Note>
