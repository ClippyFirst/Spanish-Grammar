У *gustar* і подібних **те, що подобається** — підмет; особі — непрямий додаток. Логіка «навпаки» від української «мені подобається».

## Одне речення

***Me gusta** el libro* (книга — підмет, однина); ***Me gustan** los libros*; ***Le duele** la cabeza.*

## Схема

**(OI) + gusta/gustan + підмет**

| OI | Приклад |
|----|--------|
| me | *Me gusta el café.* |
| te | *Te gustan las películas.* |
| le | *Le interesa la historia.* |
| nos | *Nos duele la espalda.* |
| os | *Os encanta viajar.* |
| les | *Les falta tiempo.* |

Для ясності: *A María le gusta… / A mí me gusta…*

## Список «типу gustar»

*gustar, encantar, interesar, fascinar, molestar, importar, doler, faltar, quedar, sobrar, parecer, tocar (черга)…*
