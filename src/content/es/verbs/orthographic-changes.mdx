Деякі «зміни» в основах — не про голосний, а про **збереження вимови** на письмі.

## Одне речення

*Tocar → toqué* (c→qu перед e); *llegar → llegué* (g→gu); *empezar → empecé* (z→c).

## Головні правила

### 1. c → qu перед e/i

Дієслова на **-car**:
- *tocar → toqué, toquemos*
- *buscar → busqué*
- *practicar → practiqué*

(Щоб лишилося [k], а не [θ/s].)

### 2. g → gu перед e/i

Дієслова на **-gar**:
- *llegar → llegué, lleguemos*
- *pagar → pagué*
- *jugar → jugué*

### 3. z → c перед e/i

Дієслова на **-zar**:
- *empezar → empecé, empecemos*
- *cruzar → crucé*
- *almorzar → almorcé*

### 4. i → y (між голосними / у певних формах)

- *creer → creyó, creyeron; creyendo*
- *leer → leyó, leyeron*
- *oír → oye, oyen; oyó*
- *construir → construyó*

### 5. g → j перед a/o (дієслова на -ger/-gir)

- *proteger → protejo*
- *elegir → elijo*
- *coger → cojo*

## Де це найчастіше видно

- **Pretérito indefinido** 1-ї особи (*yo*): toqué, llegué, empecé
- **Presente de subjuntivo**: toque, llegue, empiece
- **Imperativo / subjuntivo** інші особи

<Note kind="uk" title="Для україномовних">
  Це не «неправильні дієслова», а орфографія під вимову.
  Якщо знаєте, що *tocar* має [k], логічно писати *toqué*, а не *tocé*.
</Note>
