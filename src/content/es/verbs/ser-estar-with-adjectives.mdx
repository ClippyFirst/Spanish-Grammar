З деякими прикметниками **ser** і **estar** дають різне значення — це не «постійне/тимчасове» як єдине правило, а різні смисли.

## Одне речення

*Es listo* — кмітливий; *Está listo* — готовий. *Es aburrido* — нудний (риса); *Está aburrido* — йому нудно.

## Найважливіші пари

| Прикметник | Con ser | Con estar |
|------------|---------|-----------|
| listo | кмітливий | готовий |
| aburrido | нудний (про людину/фільм) | нудьгує |
| bueno | добрий / якісний | смачний (про їжу) / у формі |
| malo | поганий характером | погано себе почуває |
| vivo | живий (не мертвий) / жвавий | живий (у сенсі «оживає») — рідше; часто *está vivo* = живий |
| verde | зеленого кольору | недозрілий |
| rico | багатий | смачний |
| seguro | надійний / безпечний | впевнений |
| abierto | відкритий (характер) | відчинений |
| cerrado | замкнутий (характер) | зачинений |

## Не всі прикметники «парні»

- *cansado, enfermo, contento, enfadado* — майже завжди **estar** (стан).
- *español, médico, de Madrid* — **ser** (ідентичність).

<Note kind="uk" title="Для україномовних">
  Українське «нудний / готовий / кмітливий» не завжди підказує ser/estar.
  Вчіть пари listo, aburrido, bueno, malo, rico як мінімальний набір.
</Note>

<Note kind="region" title="Регіональна нота">
  Значення пар стабільні. Розмовні зсуви трапляються, для довідника — нормативні пари.
</Note>
